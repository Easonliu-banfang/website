八球台球 · 玩法规则

🎯 目标

本局采用 WPA 国际美式八球规则的主要条款。先把属于你的一组球（全色 1-7 或花色 9-15）全部打进洞，再合法打进黑八即获胜。

🚀 开球

开球合法条件：有球入袋，或至少 4 颗目标球碰库。开球进球则开球方继续击打，且桌面保持开放（开球进球不分组）。开球白球落袋为犯规，对方获头线后自由球；开球打进黑八则重新摆球、由原开球方再次开球。

🎨 分组（桌面开放）

开球之后的任意一杆，若只进了一组球，该组归击球方，对手自动获得另一组。若同一杆打进两种球，由击球方选择（点击按钮）。

🚫 犯规（对方获得全场自由球）

  • 白球落袋（任何情况）。
  • 未击中任何球。
  • 已分组时，白球先击中对方组的球（己组未清时先碰黑八同样犯规）。
  • 击球后无球入袋，且白球与目标球均未碰库。

犯规后对方可将白球放在桌面上任何位置再击球。

⚫ 黑八

  • 本组球未清完就打进黑八：判负。
  • 清组后打黑八需先报袋（点击目标袋口），黑八必须进所报的袋，进错袋判负。
  • 打黑八那杆犯规（白球落袋 / 未先碰黑八）：判负。

🕹️ 操控

  • 瞄准：移动鼠标 / 手指。
  • 击球：按住拖拽蓄力（离球越远越大力），松开击球；也可 W/S 调力度、空格 击球。
  • 旋转：Q/E 左右塞，Z/C 拉杆 / 高杆。
  • 自由球：移动落点（红圈非法 / 绿圈合法），点击放置。
  • 报袋：打黑八时先点击目标袋口，袋口会高亮。
