玩法规则

🎯 目标

吹牛 + 赌命。每局重新发牌，最后存活者获胜——别人都倒下，你还站着就是赢家。

🃏 认牌

每局指定 A、K 或 Q；只有 JOKER 是万能牌，可充当任意指定牌。

🖐️ 出牌

轮到你可以选择 1–3 张手牌暗扣上桌，并宣称它们都是本局指定牌——可以说谎。

🕵️ 质疑

轮到你时，可以继续出牌，或质疑上一位玩家；手牌出尽后只能质疑。

💥 左轮裁决

质疑成功 → 撒谎者扣动左轮；质疑失败 → 由质疑者受罚。弹巢随机（0–5），击发即淘汰。

🔁 回合流程

出牌 → 下家选择继续出牌或质疑 → 揭示结果 → 扣左轮 → 下一局重发牌。循环直到只剩一人。

⌨️ 快捷键

数字键 1–5 选牌，P 出牌，C 质疑。

手机端请横屏游玩。
